## Prerequisites

- Node.js 24+
- pnpm 11+
- A PostgreSQL database (for example a free Supabase project)
- Vercel account (optional, for deployment)

## Installation

```bash
git clone https://github.com/pebisnice/nextpress.git
cd nextpress
pnpm install
```

## Environment variables

```bash
cp .env.example apps/web/.env.local
```

Fill in the required values:

| Variable | Description |
|---|---|
| `DATABASE_URL` | PostgreSQL connection string |
| `NEXT_PUBLIC_SITE_URL` | Public URL of your site |
| `BETTER_AUTH_SECRET` | Session signing secret, at least 32 characters |
| `NEXTPRESS_API_KEY` | REST API and MCP key, at least 32 characters |

Optional settings (Redis, S3-compatible media storage, isolated admin domain) are documented in `.env.example`.

## Run database migrations

```bash
pnpm db:migrate
```

## Start development

```bash
pnpm dev
```

- Public site: http://localhost:3000
- Admin panel: http://localhost:3000/admin (the first visit creates your administrator account)
- API docs: http://localhost:3000/api/docs
- OpenAPI spec: http://localhost:3000/api/openapi.json
